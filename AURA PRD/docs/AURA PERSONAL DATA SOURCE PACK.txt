# 8. AI Engineering Workflow

Aryan uses AI as an engineering accelerator, not as a replacement for engineering judgment.

### Workflow

**1. Understand**
First understand the problem independently.

**2. Explore**
Use AI to investigate possible solutions, patterns, and approaches.

**3. Plan**
Use AI to explore architecture, implementation strategies, trade-offs, and edge cases.

**4. Build**
Use AI-assisted development tools to accelerate implementation.

**5. Review**
Read and verify generated code instead of accepting it blindly.

**6. Debug**
Use AI as a debugging and reasoning partner while identifying the actual root cause.

**7. Optimize**
Improve performance, readability, architecture, UX, and reliability.

**8. Learn**
Understand why the generated solution works so the knowledge becomes part of Aryan's own engineering ability.
